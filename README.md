# Домашнее задание 1. Рекомендательные системы

Бобровская Алёна Сергеевна

Датасет: **Amazon Review Data (2018), Video Games**.
[Первоисточник](https://cseweb.ucsd.edu/~jmcauley/datasets/amazon_v2/),
[зеркало для скачивания](https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/).

В работе сравниваются item-based CF, iALS, EASE, FM с метаданными и iALS
с собственным таргетом на основе рейтинга и давности отзыва.
Дополнительно есть FM без метаданных. Модели реализованы на NumPy и SciPy.

Задача — рекомендовать 10 товаров, которые пользователь ещё не оценивал.
Положительными считаются будущие отзывы на 4–5 звёзд. Разбиение временное,
параметры выбираются по validation NDCG@10. Вторая метрика — Recall@10.

## Запуск

Нужны Python 3.9–3.12, `curl` и примерно 4 ГБ свободной памяти.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python checks.py
python execute_notebook.py
```

Можно также открыть `experiments.ipynb` в Jupyter или VS Code и выполнить
ячейки по порядку. В сохранённом ноутбуке уже есть результаты и графики.

Данные скачиваются автоматически в `data/raw/` и не загружаются в GitHub.
Ссылки на файлы и контрольные суммы — в `results/sources.json`.
Seed = 42; правила отбора и сетки параметров описаны в ноутбуке.

## Результаты

После очистки и отбора осталось 143 803 отзыва, 40 000 пользователей и
3 996 товаров. На test оцениваются 1 098 пользователей с будущими
положительными отзывами.

| Модель | NDCG@10 | Recall@10 |
| --- | ---: | ---: |
| EASE | 0.0299 | 0.0515 |
| ItemKNN | 0.0277 | 0.0470 |
| iALS | 0.0247 | 0.0458 |
| Custom iALS | 0.0217 | 0.0401 |
| FM+metadata | 0.0175 | 0.0300 |
| FM ID-only | 0.0149 | 0.0314 |

Лучший результат у EASE с λ = 50. Собственный таргет оказался лучше базового
на validation, но хуже на test. Метаданные увеличили NDCG у FM, при этом
Recall немного снизился. Оба парных bootstrap-интервала включают ноль,
поэтому уверенного выигрыша от этих изменений нет.

## Файлы

- `experiments.ipynb` — основной ноутбук: данные, формулы, эксперименты и выводы.
- `models/` — отдельный файл для каждой модели.
- `pipeline.py` — загрузка, подготовка данных и подсчёт метрик.
- `results/` — таблицы результатов, выбранные параметры и контрольные суммы.
- `checks.py` — небольшие проверки формул, градиента FM и исключения известных товаров.
- `execute_notebook.py` — запуск всего ноутбука из командной строки.
- `build_notebook.py` — исходник ячеек; при запуске пересоздаёт ноутбук без результатов.

Выборка ограничена активными пользователями и популярными товарами.
Холодный старт не проверяется. Для метаданных предполагается, что название,
бренд и категория были известны при появлении товара; их историю изменений
датасет не содержит. Остальные ограничения и источники по моделям — в ноутбуке.
